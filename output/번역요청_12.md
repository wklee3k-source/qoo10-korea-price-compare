# 번역 요청 12/13

미번역 2568건 중 이 장은 200건. **이 파일 전체를 복사해서 다른 Claude 창에 붙여넣으세요.**

---

아래는 큐텐재팬에 올라온 **한국 화장품**의 일본어 상품명 목록입니다.
각 줄을 한국어 상품명으로 옮겨 주세요.

**이 번역이 어디에 쓰이는지 알고 시작해 주세요**
번역 결과는 화면에 보여주려는 게 아니라, **네이버 쇼핑에서 같은 상품을
찾는 검색어**로 그대로 들어갑니다. 그래서 "일본어를 한국어로 옮긴 말"이
아니라 **"한국 쇼핑몰에 실제로 그렇게 적혀 있는 이름"**이어야 합니다.
매끄러운 번역보다 실제 표기가 우선입니다.

**규칙**
1. 출력은 `상품번호|한국어명` 형식 한 줄씩. 설명·인사·머리말 없이 목록만.
2. 맨 앞 상품번호(10자리 숫자)는 **한 글자도 바꾸지 말고** 그대로.
   순서를 바꾸거나 줄을 빼지 마세요.
3. **입력 줄의 `[대괄호]`는 이 상품의 브랜드입니다.** 발굴 단계에서
   확인해둔 값이라 신뢰할 수 있습니다. 상품명을 풀 때 이 브랜드를
   근거로 삼으세요 — 예를 들어 `[ビープレーン]`이 있으면 비플레인
   제품이라는 뜻이고, 뒤따르는 제품명도 그 브랜드 라인에 맞춰
   해석하면 정확해집니다.
   **출력에는 대괄호를 그대로 쓰지 말고**, 한국 쇼핑몰 표기대로
   브랜드명을 상품명 앞에 자연스럽게 붙이거나(예: `비플레인 녹두
   약산성 클렌징폼 80ml`), 원문 상품명에 이미 브랜드가 들어있으면
   중복해서 넣지 마세요.
4. **있는 그대로 전부 옮기세요.** 프로모션 문구, 증정·세트 구성(1+1, 2+1),
   배송 문구, 괄호 안 설명, 기호까지 빼지 말고 원래 순서대로. 요약 금지.
5. 제품명은 **한국에서 실제로 쓰는 이름을 복원**하세요. 직역하지 마세요.
6. 브랜드명은 한국 공식 표기로 (アヌア→아누아, メディキューブ→메디큐브).
   **`[원문 = 한글]` 로 적혀 있으면 그 한글을 그대로 쓰세요.**
   이미 화해에서 확인해 둔 표기입니다. 다시 검색하지 마세요.
       `[セラディックス = 셀라딕스] ...` → "셀라딕스 ..."로 시작
   `[원문]` 만 있으면 아직 확인 못 한 브랜드입니다. 아래 규칙대로.
   **음차로 지어내지 마세요.** 로마자든 가타카나든 마찬가지입니다.
   `オガナセル`를 "오가나셀"로 찍어 넣었는데 실제 표기가 다르면,
   그 상품은 영영 못 찾습니다. 빈칸은 다음 회차에 다시 시도되지만
   틀린 값은 '번역완료'로 굳어 고쳐지지 않습니다.

   **한글 표기를 못 찾겠으면 로마자를 그대로 두세요.** 통째로 비우지
   말고 상품명만 옮기면 됩니다.
       ilso → ilso (그대로) + 상품명은 한글로
       GERnetic → GERnetic (그대로) + 상품명은 한글로
   한국에서도 로마자 그대로 파는 브랜드가 많습니다(VT·AHC·COSRX·
   POLA 등 이미 284건이 그렇게 들어가 있습니다). 브랜드 하나 때문에
   상품 전체를 버리는 것보다, 로마자로 두고 나머지를 옮기는 편이
   검색에 훨씬 유리합니다.
   다만 **일본어·한자 브랜드는 음차하지 마세요** — 그건 한국 검색에서
   안 잡힙니다. 그런 경우엔 비우고 (6)항에 적으면 됩니다.
7. 용량·수량(50ml, 2매입)은 그대로.
8. **라인명·번호·색상·제형을 절대 바꾸거나 빼지 마세요.** 같은 브랜드
   안에서 이것만 다른 제품이 많아, 하나만 틀려도 다른 상품이 됩니다.
       5번 글루타치온 ≠ 1번 판토텐산
       화이트 블론드 ≠ 퍼플
       에센스 ≠ 크림 ≠ 젤크림 ≠ 밤
8-1. **판매자가 붙인 홍보 문구·카테고리 태그는 그대로 두세요.**
   지우려고 애쓰지 마세요. 기계가 검색 전에 알아서 걷어냅니다.
       韓国化粧品 / 韓国コスメ / 正規品 / 並行輸入 / 送料無料
       한국화장품 / 한국코스메 / K-BEAUTY / 정품 / 공식 / 최저가
       메가와리 / 무료배송 / 이벤트 / 리뷰캠페인 / 증정
   원문에 있으면 그대로 옮기고, 없으면 굳이 넣지 마세요.

   **왜 직접 빼지 말라고 하나** — 빼는 기준이 사람마다 달라지면
   어떤 회차는 빠지고 어떤 회차는 남습니다. 그러면 나중에 "이 태그가
   검증에 해로운가"를 측정할 수가 없습니다. 원문을 그대로 두면
   기준을 한 곳(검색어 정제)에서만 바꾸면 되고, 판단이 틀렸을 때
   되돌리기도 쉽습니다.

   (실측: 이런 말이 붙은 상품의 검증 통과율이 45.0%로, 안 붙은 것
   49.2%보다 낮습니다. 그래서 검색어를 만들 때 자동으로 뺍니다.)

8-2. **"최선의 음차"로 채우지 마세요. 그건 비운 것보다 나쁩니다.**

   실측입니다. 직역·음차로 채운 건의 검증 통과율은 **14%**였습니다.
   전체 평균 48.5%의 3분의 1도 안 됩니다.

   왜 그런가 — `オガナセル`를 "오가나셀"로 찍었는데 실제 표기가
   "오가나쉘"이면 그 상품은 한국 쇼핑몰에서 **영영 안 잡힙니다.**
   그런데 값이 들어갔으니 '번역완료'로 굳어 다시 시도되지도 않습니다.

   **비우면 다음 회차에 다시 옵니다. 틀리면 끝입니다.**

   브랜드가 낯설고 검색해도 한국 판매 흔적이 없다면, 나머지 정보가
   아무리 명확해도 비우는 게 맞습니다. 그런 브랜드는 대개 한국에서
   안 파는 것이고, 비워서 알려주시면 목록에 올려 다음부터 아예
   빼드립니다.

9. 확실하지 않으면 지어내지 말고 `번호|` 로 비워 두세요.
   빈 줄은 다음 회차에 다시 시도됩니다. 틀린 값이 들어가면 '번역완료'로
   굳어 영영 고쳐지지 않으니, 비우는 편이 낫습니다.
10. **목록을 다 옮긴 뒤, 맨 아래에 피드백을 아주 상세히 적어 주세요.**
   아래 구분선을 그대로 쓰고 그 뒤에 적으면 됩니다. 구분선 아래는
   기계가 읽지 않으니 형식·분량에 얽매이지 마세요. **길수록 좋습니다.**

   ```
   ---피드백---
   ```

   이 목록을 옮기려면 상품 하나하나를 찾아보게 됩니다. 그 과정에서
   알게 된 것들이 이 사업에서 가장 값진 정보인데, 적어두지 않으면
   이 창이 닫히는 순간 전부 사라집니다. **번역 결과보다 이 피드백이
   더 오래 남습니다.**

   ### 반드시 적어 주세요

   **(1) 찾아보고 알아낸 브랜드 표기**
   일본어·영문 브랜드를 한국에서 실제로 뭐라고 부르는지 확인했다면
   전부 적어 주세요. 확인한 근거(어디서 봤는지)도 함께요.
   ```
   ミルボン → 밀본 (올리브영·네이버에서 '밀본'으로 판매)
   ululis → 우루리스 (한국 미판매, 일본 브랜드)
   La sana → 라사나 (쿠팡 표기 '라사나')
   ```

   **(2) 라인명·시리즈 체계**
   같은 브랜드 안에서 제품을 가르는 이름 규칙을 알아냈다면 적어 주세요.
   ```
   넘버즈인은 라인이 번호로 구분됨. 1번=시카, 3번=모공, 4번=콜라겐,
   5번=글루타치온. 번호를 빼면 완전히 다른 제품이 됨.
   아누아는 어성초77/어성초80/라이스70 처럼 성분+숫자로 라인 구분.
   ```

   **(3) 이 상품이 한국에서 어떤 상태인지**
   찾아보다 알게 된 것을 적어 주세요. 검증 단계에서 그대로 쓰입니다.
   - 한국에서는 안 파는 것 같다 (일본·중국·유럽 브랜드)
   - 단종된 것 같다 / 리뉴얼돼 이름이 바뀐 것 같다
   - 한국에서는 다른 이름으로 판다 (예전 이름 → 새 이름)
   - 화장품이 아니다 (영양제·잡화·가전 등)

   **(3-1) 원문이 깨져 보이면 원본을 직접 확인하세요**
   판매자 오타나 수집 과정의 손상으로 글자가 깨진 경우가 있습니다.
   (실제 사례: `ュラルテック` — 앞 글자가 빠진 `ナチュラルテック`,
   `バイレもブルランスィ` — 무슨 말인지 알 수 없음)

   상품번호로 큐텐 페이지를 직접 열 수 있습니다:
   ```
   https://m.qoo10.jp/gmkt.inc/Mobile/Goods/goods.aspx?goodscode=<상품번호 앞 8자리>
   ```
   예를 들어 상품번호가 `1203742091`이면 `goodscode=12037420` 입니다.
   (뒤 두 자리는 옵션 번호라 빼야 페이지가 열립니다)

   원본을 봐도 모르겠으면 비우고 (6)항에 적으면 됩니다.

   **(4) 망설인 지점 전부**
   ```
   医薬部外品: 한국엔 없는 제도라 망설였음. 그대로 "의약부외품"으로 옮김.
   詰め替え: "리필용"과 "교체용" 중 리필용이 더 흔해 보여 통일함.
   ○○という単語: 검색해도 한국 표기를 못 찾아 음차함.
   ```
   어떻게 옮겼는지, 왜 그렇게 정했는지까지 적어 주세요.
   **틀렸을지도 모른다고 생각한 것일수록 꼭 적어 주세요.**

   **(5) 여러 번 나온 패턴**
   같은 고민이 반복됐다면 그게 규칙이 될 후보입니다.
   ```
   "サロン専売"가 12번 나왔음. 전부 "살롱전용"으로 통일.
   용량이 "1000ml/g"처럼 섞인 표기가 8건. 원문 그대로 뒀음.
   ```

   **(6) 비운 줄은 하나하나 이유를 적어 주세요**
   같은 빈칸이라도 이유에 따라 손볼 곳이 완전히 다릅니다.
   ```
   1234567890 — 브랜드를 못 찾음. 검색해도 안 나옴.
   1234567891 — 상품명이 중간에 잘려 있어 무슨 제품인지 알 수 없음.
   1234567892 — 화장품이 아니라 커피믹스임.
   1234567893 — 일본 전용 상품으로 보임. 한국 판매 흔적 없음.
   ```

   **(7) 규칙이 서로 부딪힌 곳**
   어느 쪽을 따랐는지, 왜 그랬는지 적어 주세요.

   **(8) 이 지시문에서 고쳤으면 하는 것**
   설명이 부족했던 부분, 예시가 필요한 부분, 순서가 헷갈린 부분.
